### Задание 1

Опишите основные преимущества использования масштабирования методами:

- активный master-сервер и пассивный репликационный slave-сервер; 
#### Ответ:
Slave сервер можно использовать для резервного копирования, чтобы снизить нагрузку с основного

- master-сервер и несколько slave-серверов;
#### Ответ:
Несолько slave серверов можно использовать как источник бэкапов и как зеркала master в других дата-центрах для более быстрого доступа к данным в других странах, и для распределения нагрузки на master сервер.
